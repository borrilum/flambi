# SIMPLE_USER_GUIDE.md

## What this plugin is

Flambi Atmosphere is a simple instrument that makes:
- foggy drones
- washed pads
- smoky background textures

You can play it from MIDI notes or use DRONE mode.

## One-screen controls (ELI5)

- **TONE**: dark ↔ brighter waveform color
- **AIR**: adds soft hiss/air/noise
- **MOTION**: how much slow movement the sound has
- **DRIFT**: unstable tape-like wander
- **DIRT**: gentle saturation/grit
- **DELAY**: dubby echo amount
- **SPACE**: reverb size/wash
- **OUTPUT**: final loudness

## Buttons

- **DRONE**: holds a root note forever (until off)
- **RANDOMIZE**: picks a new tasteful atmosphere
- **INIT**: resets to startup patch
- **MONO**: single-note behavior, nice for focused drones

## Tiny controls

- **Root note**: which note DRONE uses
- **Octave**: shift DRONE up/down
- **Filter mode (LP/BP)**:
  - LP = smoother, darker
  - BP = hollow, narrow, ghostly

## Quick jam recipe in FL Studio

1. Load Flambi Atmosphere on a channel.
2. Start with preset **Mist Floor**.
3. Turn DRONE on.
4. Set root note to your track key.
5. Slowly raise MOTION and SPACE.
6. Add DELAY until it breathes with your tempo.
7. Automate TONE and AIR over 16/32 bars.

## Tips for good ambient techno texture

- Keep highs controlled (TONE lower, AIR moderate)
- Use subtle DRIFT for alive-but-stable feeling
- Don’t max every knob; moderate values sound deeper
- Layer with drums/bass, keep this plugin as atmosphere bed
